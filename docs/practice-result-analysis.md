# Разбор результата как короткий урок

Разбор после проверки задания показывает тему и короткий результат, общий
вывод, карточки неверных ответов, правило с примером и повторение. На экране
текущего ответа считается одно задание; несколько неверных старых шагов
подписываются как шаги этого задания. При правильном ответе остаются сверка
ответа и разбор решения. Номер задания берётся из сохранённой позиции сессии.

## Компоненты и данные

- `ResultAnalysis` собирает экран и сохраняет подключение AI и `learningCheck`.
- `ResultSummary` содержит заголовок и общий вывод.
- `MistakeCard` показывает условие, выбранные и правильные ответы, доступный
  авторский комментарий и сохранённые шаги решения.
- `RuleReviewCard` берёт правила из существующего `SKILLS` только по `skillIds`
  проверенного ответа; название темы и сходство формул не используются.
  Пример — сохранённое объяснение задания. При отсутствии связи с правилом
  этот блок использует только объяснение, без сгенерированной теории.
- `RetryCard` вызывает прежние `onRetry` / `onNext`. Повтор открывает то же
  задание с прежними серверными штрафами/учётом помощи. Подпись прямо сообщает,
  что ответ уже показан. Следующее задание и завершение проходят через прежний
  PATCH состояния; отдельного движка отправки или независимой проверки нет.

`lib/resultAnalysis.ts` преобразует данные исключительно для отображения.
Идентификаторы, правильность и буквы A–E берутся из сохранённого результата и
его порядка вариантов. Для multi-select отображается весь сохранённый набор.
Старые результаты с пошаговым вводом также доступны.

## Причины ошибок и формулы

Конкретный вывод показывается только по сохранённому авторскому `feedback`.
Общий конкретный вывод требует одинакового комментария у всех неверных
ответов. `unclassified`, отсутствие комментария и известный нейтральный
fallback старых шагов получают одно уведомление в summary. Техническая
классификация старого ответа сама по себе не доказывает конкретную причину.
Различающиеся авторские комментарии остаются в своих карточках.

Используются прежние `MathText`, `ChoiceMath` и `MathDisplay` с KaTeX.
`choiceStem` размечает математические фрагменты авторского текста;
`choiceLatex` форматирует коэффициенты, степени, корни, логарифмы и полные
дроби без изменения порядка операций. Например, `6*(3*x+1)` отображается
как `6(3x+1)`. Исходные ответы и формулы для проверки не изменяются.
KaTeX также выводит MathML для вспомогательных технологий.

Колонка ограничена 672 px. Длинные формулы прокручиваются внутри своих
блоков. Основные действия имеют высоту не менее 44 px. Результат обозначается
иконкой и подписью вместе с мягким цветовым акцентом. Все новые подписи
локализованы на RU/KK/EN; учебный контент сохраняет существующий RU fallback
для английского.

## Проверки

```powershell
npm run lint
npm run typecheck
npm run test:analysis:unit
npm run test:analysis:browser
npm run test:choices:unit
npm run test:choices:http
npm run test:choices:browser
npm run test:progress:unit
npm run test:session:unit
npm run test:skills:unit
npm run test:offline:unit
npm run build
```

Браузер и HTTP используют временные аккаунты и требуют приложение на
`127.0.0.1:3100` (либо `CHOICE_TEST_BASE_URL`) и БД. Новый браузерный сценарий
проверяет один/несколько неверных ответов, авторский/unclassified вывод,
правильный ответ, multi-select, длинную формулу, RU/KK/EN, 360/390 px,
desktop, повтор с клавиатуры, восстановление результата и историю.
Пошаговый исторический ответ проверяется отдельным mock публичного GET;
отправка, повтор, переход и история проверяются на реальном API.
Скриншоты сохраняются в `tmp/result-analysis/`.

`submitAttempt`, снимки `practiceChoice`, правила оценивания, Mastery,
история, офлайн-очередь и экзамен не изменены.
