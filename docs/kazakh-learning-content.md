## Модель и инварианты

Одна задача имеет один ID, набор шагов и вариантов, один ключ ответа и связи с
навыками. Русский источник и казахские поля находятся в тех же строках Prisma.
Казахский вариант ответа отображается через `textKk`; в обычной практике
отправляется прежний ID/канонический текст, в экзамене — прежний индекс варианта.
Перевод не меняет оценивание, хеш математического содержания или историю.

`Question.localizationSource` хранит точный снимок исходных текстов и порядка
шагов/вариантов. Изменение источника требует проверки перевода; просроченная
локализация не считается полной. Проверка исключает формулы, единицы измерения,
технические индексы/ключи и известные собственные математические имена.
Это проверка полноты и актуальности полей, а не автоматическое доказательство
лингвистической или математической эквивалентности каждого предложения.

KK не использует скрытый русский fallback для учебного текста. При отсутствии
перевода обычный экран показывает явное сообщение на казахском. Новая KK
диагностика требует полного банка; KK экзамен включает только полностью
локализованные, актуальные, проверенные задачи. Если квоты 20 задач, A/B/C=5/10/5
и по одному заданию на каждый пункт не выполняются, запуск возвращает 422 с
казахским объяснением дефицита. Проверенный вариант сейчас собирается.

Язык обычной тренировки не входит в ключ состояния или эффект загрузки.
Позиция, черновик, канонический ответ, подсказки, результат и UUID отправки
сохраняются при переключении и перезагрузке. Переключатель доступен и на
мобильных экранах. Язык экзамена фиксируется при старте вместе с вариантом;
переключение языка интерфейса не переписывает этот сохранённый вариант.

LaTeX и геометрические данные не переводятся строковыми заменами. Условия,
шаги и разборы используют компоненты математического отображения. Шрифт
включает `cyrillic-ext` для казахских букв.

## Безопасное обновление существующей базы

Сначала примените предыдущие аддитивные обновления проекта, если база ещё
не содержит навыки, диагностику, дневные планы и экзаменационный режим.
Затем:

```powershell
npx prisma db execute --file prisma/updates/20261005_kazakh_learning_content.sql --schema prisma/schema.prisma
npm run db:generate
npm run db:kazakh
npm run content:audit
```

SQL использует `ADD COLUMN IF NOT EXISTS`. Заполнение выполняется в транзакции
с advisory lock и обновляет только локализационные поля существующих строк.
Неизвестный текст, неполный перевод или изменённый источник прерывает заполнение
с откатом: добавьте проверенный перевод и только затем повторите операцию.
Не удаляйте `localizationSource` для обхода проверки. Для изменения исходного
материала обновляйте перевод и снимок источника вместе после проверки.

Повторное выполнение не создаёт задач, шагов, вариантов, тем или навыков,
не обновляет ключи ответов, попытки, планы, результаты и пользовательские данные.
Генератор новых задач и обычные заполнения навыков/экзамена подключены к этой
модели переводов. `db:reset` не является процедурой миграции существующей базы.

## Проверки

```powershell
npm run content:audit
npm run test:kazakh:unit
npm run test:kazakh:ai
npm run build
# Запустить production-сервер для HTTP-проверки:
npm run start -- --port 3100
# В другом терминале, либо задать KAZAKH_TEST_BASE_URL:
npm run test:kazakh
```

Проверены 400 сгенерированных задач, авторский экзаменационный банк, KaTeX,
неизменность геометрии, варианты с текстовыми ответами, равенство оценок RU/KK,
отсутствующие/скопированные/просроченные переводы. HTTP-проверка проходит
диагностику → теорию → практику → ошибку → план → экзамен → результат 12/20,
переключает язык сохранённого черновика/подсказки/результата, повторяет DDL и
заполнение дважды, проверяет сохранность записей ученика и отказ неполного KK
экзамена. Тестовые аккаунты удаляются по собственным IDs и уникальным email.

Пройдены прежние unit/HTTP-наборы авторизации, прогресса, устойчивости тренировки,
навыков, дневного плана, покрытия банка, математики SymPy и экзаменационного режима.
Браузерная проверка подтверждает сохранение выражения, подсказки, разбора ошибки,
позиции второй задачи и её ответа после переключения RU↔KK и перезагрузки.

AI проверен с имитацией провайдера: успешный казахский ответ, локализованный
контекст, сохранённый анализ, некорректный JSON, русский ответ и отсутствие ключа.
Русские пояснения с обнаруженными русскими словами отклоняются, после неудачных
попыток возвращается казахское сообщение. Эвристика не заменяет языковую проверку.

## Материалы для языковой вычитки

Независимая вычитка преподавателем математики — носителем казахского языка
пока не выполнена. Она нужна для всех новых переводов старого/генерируемого
банка, 33 экзаменационных заданий, 20 экзаменационных правил, геометрических
пояснений и дополненных системных сообщений; полезна также для прежних 15
уроков и диагностических/дневных материалов. Особое внимание: определения
областей функции, геометрические термины «жасаушы», «жазба», «қиық», условия
дифференциальных уравнений и единый стиль обращения к ученику.

Живые ответы внешнего AI не прошли отдельную оценку носителем языка.
Автоматические проверки подтверждают маршрутизацию/защиту/fallback, но
не гарантируют качество произвольного ответа внешней модели.
