## Какая именно спецификация используется

Это «Спецификация теста по дисциплине “Математика” естественно-математического
направления для единого национального тестирования для поступающих по
образовательным программам высшего образования, предусматривающим сокращённые
сроки обучения», **для использования с 2023 года**.

На дату проверки НЦТ размещает её в пакете **B057 “Информационные технологии”**
на действующей странице подготовки к ЕНТ ТиПО. Другая редакция для B057 с
пометкой 2026 не обнаружена. Дата размещения архива, год документа и дата
проверки хранятся отдельно. Документ не переименован в «спецификацию 2026».

Целевая категория — выпускники ТиПО/ТжКБ по Software Development:
`06130100` “Программное обеспечение (по видам)”, включая квалификацию
`4S06130103` “Разработчик программного обеспечения”, поступающие на родственное
направление B057 с сокращённым сроком обучения. В перечне родственных
направлений связь видна на PDF-страницах 208–210 (печатные страницы 209–211).
Для поступления на полный срок обучения или другую ГОП нужен отдельный
профиль. Обычная школьная спецификация здесь не использована.

Официальные источники:

| Математика | 20 закрытых заданий, один правильный ответ из четырёх |
| Баллы математического блока | Правильный ответ — 1, неправильный — 0; максимум 20 |

20 пунктов охватывают 11 разделов. Проверяемые умения: исследование функций
и графиков; решение тригонометрических уравнений и неравенств; многочлены
нескольких переменных; корни и иррациональные преобразования; производные и
касательные; первообразные и неопределённые интегралы; комплексные числа;
дифференциальные уравнения; поверхности и объёмы тел. Номера, содержание,
связанные навыки и страницы источника перечислены в `lib/exam/profile.ts`.
Широкий пункт может включать несколько умений: одна задача не подтверждает
освоение или исчерпывающее покрытие всего пункта.

## Как устроены данные и проверка

`EXAM_PROFILES` — реестр профилей с идентификатором, версией, годом документа,
категорией поступающих, источниками, датой проверки и нумерованными пунктами.
Официальные параметры находятся в `official`, внутренние — в `platformPolicy`.
Новый профиль добавляется отдельной записью; чужие проверки нельзя переносить
между профилями или версиями без предметного пересмотра. В этой версии
реализован формат общепрофессионального блока с одним ответом из четырёх.
Новые форматы требуют расширения валидатора формата и правил доступности.

Проверки старого банка находятся в `lib/exam/legacy-reviews.json`.
190 отпечатков описывают 475 исходных строк, включая точные копии.
Связь содержит профиль и его версию, пункт, качество, объяснение границ
соответствия, семейство решения, дату, навыки и SHA-256 содержания. Отпечаток
учитывает условие, LaTeX, эталоны, объяснение, типы/варианты шагов, назначение
и сложность; название темы и произвольный ID не дают соответствия.
Изменённая или неизвестная задача автоматически требует новой проверки.

Проверялись условия, этапы решения и ответы исходных задач; для шаблонов
пересчитывались коэффициенты, значения и варианты. Производная монома
соответствует пункту 10; квадрат двучлена одной переменной лишь поддерживает
пункт 05. Табличный синус не заменяет уравнение; вычисленный логарифм не
покрывает анализ графика. Проверки не назначают старым задачам A/B/C через
простую конвертацию числового поля `difficulty`.

Качество имеет четыре состояния: `direct`, `supporting`, `outside`,
`needs_review`. Отдельно проверяются фактический формат, сохранённая связь
с навыком и пригодность для будущего экзамена. Многошаговая тренировка даже
с промежуточным выбором ответа не считается цельным экзаменационным заданием.
Задания диагностики и независимой проверки знаний не попадают в экзаменационный
подбор. Старые задания и история попыток не переписаны.

Добавлены 30 авторских задач с одним ответом из четырёх и сохранёнными
`QuestionSkill`/`StepSkill`. Приоритет — отсутствовавшие форматы и содержание:
уравнения с обратными функциями, тригонометрические неравенства, многочлены
нескольких переменных, свойства графиков по точкам, развёртки, поверхности,
призмы и усечённые тела. Это учебные задачи платформы, не вопросы НЦТ.
Новые навыки хранятся отдельно от трёх навыков входной диагностики: её охват
не расширился автоматически.

Семейство означает способ решения, а не новый набор коэффициентов. Например,
объём цилиндра, восстановление высоты конуса по образующей и объём усечённого
конуса — разные семейства. Уровни новых задач назначены содержательной
проверкой; эмпирическая калибровка A/B/C ещё не проведена. Независимый SymPy
пересчитывает ответы, проверяет единственность верного варианта, области
определения, диапазоны обратных функций и границы интервалов.

## Состояние проверенного checkout

[Машиночитаемый снимок](exam-coverage-report.json) отражает текущую базу после
сидинга. Экран `/exam-coverage` и API `/api/exam-coverage?profile=ntc-tipo-b057-math-2023`
пересчитывают отчёт из БД при каждом запросе; количество не берётся из README.

Всего **505** задач: **185** прямых соответствий содержания, **275**
вспомогательных, **17** вне профиля, **28** требующих проверки.
Пригодны по формату, связям с навыками и назначенному уровню **30**.
65 групп содержат точные копии (285 повторных строк). Метки тем 267 задач
не совпадают с пунктом их фактического содержания; значительная часть —
результат старого расширения банка с неправильной привязкой тем.

Прямые соответствия есть у **18/20 пунктов**. Раздел дифференциальных
уравнений не покрыт: старые задачи первого порядка содержат ошибки эталонов
и выбора метода; задания второго порядка в основном проверяют только корни
характеристического уравнения. Пункты **12, 15, 16** не имеют пригодного
экзаменационного формата. 11 пунктов имеют меньше трёх разных семейств.
Даже остальные семь требуют проверки полноты всех внутренних умений.

По формату и квотам сложности можно подобрать один набор из 20 задач.
Это не доказывает полное соответствие темам официального варианта, поскольку
НЦТ не публикует здесь тематические квоты. Для трёх вариантов без повторения
семейств нужно 60 задач: доступно 30, дефицит по 10 задач A, B и C.
Внутренний сбалансированный вариант с одним заданием на каждый пункт не
собирается: доступно 17 из 20. Такой баланс — требование платформы, не НЦТ.
`assessExamReadiness` использует целочисленный максимальный поток, чтобы
учитывать одновременно пункты, уровни, семейства и исключать двойной подсчёт.
Возвращает явный дефицит для будущего генератора, не подменяет задачи копиями.

Вне выбранного профиля отмечены определённые интегралы и интегрирование
произведений по частям, явно не перечисленные в пунктах 12–13. Часть задач в
теме “Экспоненциальные интегралы” в действительности проверяет производную
или степени; поэтому внепрофильность определяется по задаче, а не всему названию.

Новые навыки не расширяют текущую диагностику автоматически. Ежедневный

добавление непроверенного у ученика навыка в каталог само по себе не является
основанием назначать повторение. После решения нового задания связанный
экзаменационный навык участвует в плане на общих основаниях.

## Запуск и воспроизводимость

Изменения схемы БД не требуются. Для существующей базы с темами t1–t15:

```powershell
npm run db:exam
npm run exam:audit
npm run test:exam:unit
npm run test:exam
npm run test:exam:math
npm run build
```

Первоначальный `npm run db:seed` теперь также вызывает сидинг экзаменационного
банка. Сидинг добавляет темы/навыки и вопросы со стабильными ID, сериализует
параллельные запуски, не создаёт повторные строки и сохраняет существующее
содержание. Конфликт уже занятого ID с новым условием прекращает транзакцию.

`exam:audit [profileId] [outputPath]` сохраняет JSON с профилем, датой
источников, временем построения, всеми ID и отпечатками задач, причинами,
счётчиками, отсутствующими разделами и запасом для вариантов. При смене БД
снимок нужно пересоздать; UI и API всегда используют живую базу.

`test:exam:math` использует SymPy из существующего контейнера `entTIPO_math`.
Без Docker можно выполнить `npx tsx scripts/export_exam_math.ts | python
scripts/verify_exam_math.py` в среде с SymPy. Для HTTP-проверки запустите
собранное приложение на порту 3100 и выполните `npm run test:exam:http`
(или задайте `EXAM_TEST_BASE_URL`). Тест проверяет доступ, неизвестный профиль,
счётчики, отображение непокрытого раздела, отправку нового вопроса и запись
связанного навыка; свои фикстуры удаляет.

Проверки выполнены на локальной PostgreSQL и production-сборке Next.js:
`test:exam:unit`, `test:exam`, `test:exam:math`, `test:exam:http`,
`test:plan:unit`, `test:plan`, `test:skills`, остальные модульные проверки
аутентификации, прогресса, сохранения сессий и навыков, а также `npm run build`.
Все прошли. В HTTP-проверке новый навык после первой попытки входит в план;
неисследованные навыки каталога не вытесняют диагностированные навыки.

Скрипт расширения старого пула больше не записывает произвольные генераторы
в чужие темы; сохраняет точное значение объёма и пропускает точные копии.
Исправлены повторяющиеся варианты генераторов логарифмов, тригонометрии,
касательных и ДУ. Новые случайные варианты не получают предметную проверку
автоматически: незнакомые отпечатки отображаются как `needs_review`.
