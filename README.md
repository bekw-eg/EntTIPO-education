# Synaq — пробный тест по математике

Сайт для выпускников колледжей: **математика ЕНТ ТиПО, B057 «Информационные технологии», сокращённый срок обучения**.

Сценарий: вход или регистрация → пробник → балл и разбор → «Мои результаты».
Навигация: «Пробник», «Мои результаты», «Аккаунт». Главная `/` открывает пробник; `/exam` сохраняется как совместимый адрес.

Пробник содержит 20 авторских заданий, четыре варианта ответа, максимум 20 баллов.
Поддерживаются русский и казахский языки; сервер проверяет достаточность и актуальность банка перед запуском.
Учебный лимит времени Synaq не является официальным нормативом ЕНТ.
Банк содержит 33 проверенные экзаменационные задачи: повторения между попытками возможны.

Сохранены серверный таймер, автоматическое завершение, изменение ответов, отметки «вернуться»,
автосохранение и продолжение попытки после повторного входа. Ответы и решения открываются
после завершения. Разбор прежних результатов закрыт на время активной попытки, чтобы не раскрывать ответы.
История принадлежит аккаунту и включает все сохранённые попытки.

## Запуск

Нужны Node.js 20.9+ и Docker Desktop.

```powershell
npm ci
# Настройте .env по .env.example, включая DATABASE_URL и SESSION_SECRET.
docker compose up -d
npm run db:generate
npm run dev
```

Для production обязательны постоянный `SESSION_SECRET` и доступная PostgreSQL.
При обновлении существующей базы используйте необходимые аддитивные SQL-файлы из
`prisma/updates`; данные не сбрасывайте. Эта задача не меняет схему БД.
Для новой пустой базы порядок заполнения и проверки банка описан в
[документации пробника](docs/exam-mode.md) и [аудите спецификации](docs/exam-specification-coverage.md).

## Проверки

```powershell
npm run typecheck
npm run build
npm run test:auth:unit
npm run test:exam-mode:unit
npm run test:exam:unit
npm run test:exam:math
```

При запущенном приложении на порту 3100:

```powershell
$env:EXAM_TEST_BASE_URL = "http://127.0.0.1:3100"
$env:AUTH_TEST_BASE_URL = "http://127.0.0.1:3100"
npm run test:auth
npm run test:exam-mode
npm run test:exam:http
npm run test:ui:smoke
npx tsx scripts/test_public_exam.ts
```

Браузерный smoke проверяет регистрацию, вход, сохранение/восстановление, завершение,
историю и экраны шириной 360, 390, 768 и 1440 px. Скриншоты сохраняются в `tmp/exam-ui`.
Нужен установленный Chromium Playwright или `PLAYWRIGHT_CHROMIUM_EXECUTABLE`.

## Отложенные разделы

Программа, «Мой путь», план дня, диагностика, отдельные тренировки, каталог и теория,
AI и подсказки, отдельные ошибки, учебная статистика, геометрия, офлайн-пакеты и публичное
покрытие экзамена исключены из интерфейса. Прямые адреса страниц перенаправляются на пробник.
Диагностика, AI, подсказки, офлайн-API и публичный API аудита возвращают 410.
Код, общие зависимости и прежние данные сохранены; остальные учебные API остаются
внутренними совместимыми сервисами с прежними проверками защиты ответов.

Аудит банка — внутренний инструмент: `npm run exam:audit`. Не публикуйте полный отчёт через API.
`/api/exams/availability` возвращает только доступность языков и номера недостающих пунктов.
Старый service worker заменяется сетевым обработчиком; офлайн-данные в IndexedDB не удаляются.

Оплата не подключена, ограничений бесплатных попыток нет. Будущая модель:
первый пробник бесплатно, последующие по 150 тг — после реализации учёта и оплаты.
