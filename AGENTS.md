# Project Git workflow

- Repository: https://github.com/bekw-eg/EntTIPO-education.
- Work in this checkout. Create a separate `feature/<feature-name>` branch for each new feature, with a descriptive name. This user-requested prefix takes precedence over a default `codex/` prefix.
- Commit and push completed changes to the corresponding feature branch.
- All commits must use the owner's Git identity: `user.name=bekw-eg` and the owner's email already configured in this repository's local Git configuration. Verify both author and committer before committing; keep this identity for every feature.
- Do not add assistant or AI co-author trailers or replace the owner's identity with an assistant identity.
- Use the owner's authenticated GitHub account (`bekw-eg`) when pushing.
